# Mining income

_Generated by `lune run tools/mining_economy`. Don't edit by hand._

Mining $/h is the supply of **one chamber** (the mix in `MiningLogic.Mix`). A faster pick cannot outrun respawn. Net value is the better of the chunk and the ingot after the coal a smelt burns (`chunkValue / 4`). Comparison wood is the best wood the player can already reach, from ECONOMY.md's "$/h cap a player (shared by 4)" column. Hills: Pine. Snow: Frostwood (higher than Emberwood). Gloam compares with Frostwood too, because a deep miner can already sell it. The 0.8× cap there is $22,942. Gloamwood itself ($7,262) stays in `WoodIncome.gloam` so this tool can see it move, and it is not the comparison. That column is the biome supply cap, not the buying-path wage.

`profile.mining` is account-wide, like the pick level. A slot swap does not move it. The Obsidian turn-in is saved as `crafted.HeartstoneTurnIn` so an older save still reads.

Cap: mining stays at or under **0.8×** that wood. The tool fails above it, and it fails if a deeper tier's best rate or best ingot is below the tier above.
